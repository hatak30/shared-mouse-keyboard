Screen layout

Drag machines so they match where the screens physically stand. The cursor moves to a neighbouring machine when it reaches the shared edge. Machines that only touch at a corner are not connected.

Unsaved changes

Not placed — paired machines that are not in the layout. Drag them onto the grid, or drag a machine here to remove it.

Hotkeys: Ctrl+Alt+Shift+←↑→↓ jumps to the neighbouring machine, Ctrl+Alt+Shift+Enter brings the cursor back to this machine.

Machines

Computers running Shared Mouse & Keyboard on your network appear here automatically. Pair a machine once to let it share input and clipboard with this one.

Add by address

If a machine does not show up (for example on networks that block broadcast), enter its IP address or host name.

Permissions

The operating system must allow this app to read and simulate mouse and keyboard input, and to talk on the local network.
